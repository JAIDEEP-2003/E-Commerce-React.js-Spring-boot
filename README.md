# 🛒 E-Commerce Web Application (React.js + Spring Boot)

## 📌 Overview

This project is a **Full Stack E-Commerce Web Application** developed using **React.js** for the frontend and **Spring Boot** for the backend.
It allows users to securely log in, manage their shopping cart, and place orders through REST APIs.

---

## 🚀 Features

* 🔐 User Login & Signup (JWT Authentication)
* 🛍️ Browse Products
* ➕ Add Products to Cart
* 📦 Place Orders
* 🔄 REST API Integration
* 🔒 Secure Authentication using JWT

---

## 🏗️ Tech Stack

### Frontend:

## ⚙️ How to Run the Project

### Backend Setup

1. Open `backend` in IntelliJ / Eclipse

2. Configure MySQL database in:

   application.properties

3. Run Spring Boot Application

---

### Frontend Setup

Run:

```bash
cd frontend
npm install
npm start
```
